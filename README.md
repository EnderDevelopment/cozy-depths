# Cozy Depths Minecraft Modpack

Cozy Depths is a Fabric Minecraft modpack for players who want a cozy home, immersive rain and indoor sounds, atmospheric mining, gentle new mobs, shaders, and easy quality-of-life mods. It targets Minecraft Java Edition 1.21.1 and pairs Iris and Sodium with the Complementary Reimagined shader pack.

## Install

1. Install the Modrinth App and create a Minecraft 1.21.1 instance with Fabric Loader.
2. Install the Fabric mods listed in `mods-list.md` using the Modrinth App. Choose files marked for Fabric and Minecraft 1.21.1, and let the app resolve dependencies.
3. Install Complementary Reimagined as a shader pack through the app or its project page.
4. Launch the instance once to create its folders. Back up existing worlds before adding content mods.

The included downloader script can fetch compatible Modrinth releases into a `Rainy-Hearth-1.21.1` folder. Run it with Python 3.9 or newer and an internet connection, then copy the folder contents into your Fabric instance. It selects the latest compatible releases available when run, so downloaded versions may change over time.

## Use

1. Select the Complementary Reimagined shader in Options → Video Settings → Shader Packs. Start with the Low or Medium preset and adjust settings to suit your laptop.
2. Settle in at home and explore the weather ambience and room acoustics from AmbientSounds and Sound Physics Remastered.
3. Take Traveler’s Backpack, maps, food, and torches when heading underground. AppleSkin shows hunger and saturation information; it does not add food or make food infinite.
4. Use EMI for recipes, Jade for block and entity information, and Waystones for travel between discovered locations.
5. Adjust optional features such as minimap, inventory sorting, and Simple Voice Chat in their mod settings.
